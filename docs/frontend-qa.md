## 수정한 문제

### 잘못된 주소가 정상 화면으로 열리는 문제

`#/does-not-exist`가 과제 목록으로, `#/settings/does-not-exist`가 알림 설정으로 열렸습니다. 주소 분석을 `src/app/routes.ts`로 분리하여 지원하는 경로만 선택하도록 수정했습니다. 알 수 없는 메뉴·설정 하위 주소·중첩 경로는 별도 안내 화면에서 시작 안내와 내 과제로 돌아갈 수 있습니다. 기존 상세·수정·이력 주소와 마지막 슬래시는 유지합니다.

### 열린 탭의 날짜 기준이 고정되는 문제

앱 시작 시 한 번 정한 날짜를 계속 사용하고 있어 한국 자정을 지나도 오늘·이번 주 집계 기준이 바뀌지 않았습니다. 현재 시각에서 한국 날짜를 계산하고, 다음 분 경계 및 창 복귀 시 시각을 갱신하도록 수정했습니다. 과제·공지·검토 상태를 새로 만들지 않고 날짜와 예정 미리보기만 다시 계산합니다.

자정·연말 경계와 백그라운드에서 늦게 실행된 갱신은 가짜 시계를 사용하는 회귀 테스트로 확인했습니다. 실제 자정까지 브라우저를 대기시킨 검증은 아닙니다.

## 실패 경로의 단위 검증

손상·과대 백업, 지원하지 않는 버전, 중복 과목, 저장 공간·권한 오류, 과목 삭제의 대상 키 제한, 검토 중 직접 수정한 값의 덮어쓰기 방지, 완료 후보 재실행의 중복 방지를 메모리 저장소·순수 상태 전환 테스트로 확인했습니다.
