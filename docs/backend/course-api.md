모든 응답은 HTTP 200과 `success`, `code`, `message`, `data`를 사용합니다. 삭제 요청에는 본문과 Content-Type이 필요하지 않으며 본문이 있으면 거부합니다. 쓰기 요청의 Origin·CSRF 검사는 유지합니다. 요청·응답 필드와 예시는 [API 명세](api.md), 오류는 [오류코드 정의서](error-codes.md)에 있습니다.

## 조회·입력·소유권

사용자 ID는 서버 세션에서만 가져옵니다. 타인 과목·없는 과목·삭제한 과목의 상세·수정·삭제는 같은 NOT_FOUND입니다. 비활성·탈퇴 사용자는 차단합니다. 쓰기는 사용자 행을 공유 잠금으로 검사해 검사 도중 탈퇴 상태로 바뀌지 않도록 합니다.

목록은 명시적 term을 받으며 삭제 표시 과목을 제외합니다. 이름·분반의 C 정렬과 ID로 순서를 고정하고 page 0부터, size 기본 50·최대 100으로 조회합니다. 건수와 목록은 같은 REPEATABLE READ 스냅샷에서 읽습니다. 알 수 없는 쿼리·중복 단일 쿼리·잘못된 UUID·정수는 거부합니다.

과목명·분반은 NFC·양끝 공백 제거 후 각각 UTF-16 100자·30자까지 저장합니다. 중복 키는 Locale.ROOT 소문자화로 만들고 DB의 활성 과목 유일 인덱스로 동시 등록도 제한합니다. 요일은 중복 없는 ISO 1~7이며 정렬해 응답합니다. 요일이 없으면 startTime=null, 있으면 HH:mm을 받습니다. 00:00은 보존하고 24:00·초·문자열/소수 요일은 거부합니다. startTime 키는 null이어도 생략하지 않습니다.

## 수정·이력·삭제

현재 버전을 먼저 확인하며, 값이 같더라도 오래된 expectedRevision은 REVISION_CONFLICT입니다. 같은 버전·같은 값이면 버전·시각·이력을 바꾸지 않습니다. 수정 한도는 JavaScript 안전 정수 상한인 9007199254740991입니다.

학기·과목명·분반이 바뀌면 과목 행을 먼저 잠그고 연결 과제를 ID 순으로 잠급니다. 과제 버전을 올리고 당시 과목 정보가 포함된 before/after 사본을 manual-edit 이력으로 추가합니다. 기존 이력과 제출 상태·마감·메모는 보존합니다. 수업 요일·시작 시각만 바뀌면 과목 버전만 변경합니다. 이력 저장 실패나 연결 과제의 버전 한도 초과는 과목·모든 과제·이번 이력을 함께 롤백합니다.

삭제는 courses.deleted_at과 과목 버전을 변경합니다. courses 행·tasks.course_id·과제·기존 이력을 지우지 않습니다. 활성 목록과 상세에서 제외하고 새 키로 같은 이름·분반을 재등록할 수 있습니다. 과거 학기는 학기 목록에 남습니다. 삭제한 과목에 새 과제를 연결하지 않는 검사는 다음 과제 API 단계에서 구현합니다.

## 생성 재시도

Idempotency-Key는 사용자별 UUID입니다. 사용자·키의 트랜잭션 advisory lock으로 같은 키의 동시 실행을 직렬화합니다. 정규화 본문·작업 경로의 SHA-256과 최초 성공 본문을 같은 트랜잭션에 저장하고 24시간 재사용합니다. 같은 키·다른 내용/작업은 IDEMPOTENCY_CONFLICT이며 실패한 요청은 기록하지 않습니다. 다른 사용자는 같은 키를 독립적으로 사용합니다.

재시도는 현재 과목을 다시 생성하거나 조회하는 동작이 아니라 최초 성공 결과 재전달입니다. 생성 뒤 과목을 수정·삭제했어도 만료 전 같은 키의 재시도는 최초 결과를 반환하며 실제 현재 상태는 상세/목록에서 확인합니다. 만료한 키로 새 요청을 처리할 때는 해당 만료 기록만 교체합니다. 전체 만료 기록의 정기 정리는 운영 준비 단계에서 추가합니다.
