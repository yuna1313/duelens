# 과목 필수 등록 흐름과 개발 현황

확인일: 2026-11-25. React 화면·탭 내 상태를 검증한 기록입니다. 실제 서버 저장·사용자 인증·학교 연동 완료를 뜻하지 않습니다.

## 이번 단계

- [x] 과제 추가·수정에서 과목명·분반 직접 입력 제거, 등록한 과목 선택 필수
- [x] 선택 학기에 과목이 없으면 과목 등록 안내 → 연도·학기·과목·분반 등록 → 과제 추가로 연결
- [x] 과목은 있어도 학기를 선택하지 않은 경우 학기 선택부터 안내
- [x] 과목 ID를 기준으로 과목명·분반·학기를 반영하며 연결 해제·없는 과목의 새 과제 등록 거부
- [x] 과목 목록에서 사라진 기존 연결은 당시 정보를 보존하며, 새 과제에는 재사용하지 않음
- [x] 공지 검토의 새 과제도 같은 학기·과목·분반이 등록되어 있어야 생성
- [x] 예시 과제는 전용 예시 과목에 연결하고 사용자 과목 저장·백업과 분리
- [x] 예시 공지 검토가 사용자 직접 등록 과제를 수정하지 않도록 대상 구분

과목·수업 화면의 ‘과제 미리보기용 예시 과목’은 개발 화면에서만 표시하는 읽기 전용 목록입니다. 새로 추가하는 사용자 과제는 직접 등록한 과목만 선택할 수 있습니다. 과목과 선택 학기는 브라우저에 저장되고, 과제·공지·검토·이력은 탭 메모리에 보관되어 새로고침하면 초기화됩니다.
